A face recognition notebook by Charles Goldberg and Zach Haala:

https://programminghistorian.org/en/lessons/facial-recognition-ai-python

A version with commented code.

The data are not included in this repository. The notebook uses six yearbooks (1911, 1921, 1931, 1941, 1951, 1961) from the Bethel University Digital Library, licensed CC BY-NC 3.0: https://cdm16120.contentdm.oclc.org/digital/collection/p16120coll2

Students of the course get them as a zip file on Brightspace.
